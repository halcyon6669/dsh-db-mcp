v0.9.6 - connect other agents from the panel, switch tools off

Added
- Streamable HTTP endpoint at http://127.0.0.1:8765/dsh-db-mcp, started
  automatically with the plugin. The path is configurable with --path /
  DB_MCP_PATH, and if 8765 is taken the next free port is used.
- "Connect" tab: shows the endpoint and its port, starts and stops the
  service, and writes the MCP entry for VS Code, VS Code Insiders, Cursor,
  Claude Code, Claude Desktop and Codex in one click (HTTP for the four
  editor/CLI clients, stdio for Claude Desktop and Codex).
- "Tools" tab: lists the nine agent tools with an individual switch, plus a
  default row count for sample_rows (20) and execute_sql (200).
  mcp__db__session_scope is deliberately not switchable.
- The Python server accepts --stdio / --http / --sse / --host / --port /
  --path, with DB_MCP_TRANSPORT, DB_MCP_HOST, DB_MCP_PORT and DB_MCP_PATH
  as equivalents.

Changed
- READMEs rewritten around the import -> shared registry -> shared MCP
  server story, each opening with a one-page map of the whole flow.
- New bilingual usage map (asset/usage-guide.en.png, usage-guide.zh.png)
  including an optional "point another agent at the same server" step.
- docs: "Connect another agent" chapter, /http/* and /clients routes,
  runtime requirements (Node 22.5+, Python 3.10+).

Fixed
- The dependency list no longer touches its "Install / repair dependencies"
  button in the runtime panel.
- The row-count fields are centred and align on one column.
- The Connect tab now lists only the clients this platform can actually write:
  VS Code paths resolve per OS (APPDATA, ~/Library/Application Support, or
  ~/.config) and Claude Desktop is hidden where it does not exist, so the
  panel never offers a target it cannot configure.
